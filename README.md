# JARcade :)

Three classic games in your terminal. No Java needed.

```sh
npx jarcade
```

## Games

- **Tic Tac Toe**: get three in a strech to win
- **Wordle**: guess the 5-letter word in 6 tries
- **Hangman**: guess the word before you are ...hanged (x_x)

## Install

**Try it:**

```sh
npx jarcade
```

**Keep it:**

```sh
npm install -g jarcade
jarcade
```

Needs [Node.js](https://nodejs.org/).

## Works on

- Windows (64-bit)
- Linux (64-bit)
- macOS (Apple Silicon)

The right build is picked for you.
